## FAQ (4 questions, below the tiers)

**What is hosted usage?**
We run your AI requests on our servers. Your plan includes a monthly allowance. Need more that month? Buy a top-up pack. No overages, no surprises.

**Can I use my own API key on Pro?**
Yes. Pro adds hosted usage on top. Your own keys always work.

**What happens when my free trial runs out?**
You keep using Juno with your own key. Everything works the same. The trial is a small amount of hosted usage so you can try Juno before setting up an API account.

**When do Pro features launch?**
We are shipping them through launch. Founding members and subscribers get each feature as it goes live. The founding price reflects that some are still being built.
