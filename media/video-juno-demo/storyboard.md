## The one sentence

"I built Juno so that I can ask my Mac to do something and watch it get done."

## Why this cut

- The person: a Mac user who has tried Siri for anything past a timer and gave up, or a dev who has seen computer-use demos that drag the mouse around.
- The moment: the first answer. If it comes back as a card with a button, not a paragraph, they lean in.
- The proof: the Open button opening the real folder, Calculator doing the real math, and dictated words landing in a real text field.

## Prep (before hitting record)

1. Quit everything except Juno. Hide the Dock if the wallpaper is busy. Plain wallpaper. Single display.
2. Juno: new conversation, pill centered, chat pane empty. Confirm the version in About is 0.8.172.
3. Rehearse off camera, once each: the folder question, the Calculator task, a dictation hold into TextEdit. Note the time each takes. If any one fails twice, cut that beat and shorten the video. Do not stage it.
4. Open a blank TextEdit document for the dictation beat. Nothing else open.
5. Park the mouse in the bottom right corner and do not touch it during the screen pass. The still cursor is the point.
6. Do Not Disturb on. Read `narration.txt` aloud twice.

## Recording rule

Screen first, silent, mouse parked. Each beat can be re-run, but a re-run of B01 or B03 is a new Juno turn, so start a new conversation before each full take so the chat pane stays clean. Voice after.

## Error states

| If this happens | Do this |
|---|---|
| Juno takes more than 15 s on a turn | Keep rolling. Cut the wait to about four seconds in the edit. Say nothing about speed. |
| The folder answer is a paragraph, not a card | Re-run once with "list the files in the @ folder on my desktop". If it is still prose, keep the prose take and change the B01 line to "and it listed them". Never fake the card. |
| Open is a follow-up turn instead of a direct open | Keep rolling if it ends on the right folder. If it opens any other folder, stop, close it, start over. |
| Calculator does the wrong math | Keep the take, say "and it got it wrong" in the voice pass, or re-run. A wrong answer is a true answer. |
| Dictation types the wrong words | Keep it if it is close. It is the one beat where imperfect reads as honest. |
| Any real file or folder appears | Stop. Close it. Start over. That take is trashed. |
